# Loupedeck Legacy Marketplace

Static archive of the Loupedeck v5.8 marketplace, hosted on GitHub Pages + GitHub Releases.

The old marketplace web app (`marketplace.loupedeck.com`) was shut down as part of the migration to Logitech infrastructure. This repo provides:

- **[notice.html](notice.html)** — Landing page for old v5.8 clients redirected from `marketplace.loupedeck.com`. Explains the situation and links to the new Logi marketplace and latest software downloads.
- **[index.html](index.html)** — Searchable listing of all legacy plugins, profiles and icon packs available for manual download.
